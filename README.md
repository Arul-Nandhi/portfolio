# Developer Portfolio

A high-end, production-ready developer portfolio for Arulnandhi K. Built with React and Vite, featuring smooth Framer Motion animations, a clean light theme, and a fully responsive design.

## 🚀 Features

- **Modern UI:** Clean, professional light theme using Ocean Blues, Mint Greens, and Pinks.
- **Smooth Animations:** Integrated with Framer Motion for scroll-reveals and interactive UI elements.
- **Responsive Design:** Fully optimized for desktops, tablets, and mobile devices.
- **Component Based:** Clean and scalable React structure.
- **Contact Form & Socials:** Easily connects with potential recruiters.
- **Project Showcase:** Detailed cards displaying relevant software engineering projects.

## 🛠️ Tech Stack

- **Frontend:** React (v19), HTML5, CSS3 (Vanilla)
- **Tooling:** Vite, ESLint
- **Libraries:** Framer Motion, React Icons, React Scroll
- **Deployment:** Netlify

## ⚙️ Local Development

Follow these steps to run the project locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

## 📂 Project Structure

